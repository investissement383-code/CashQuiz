# CashQuiz 🚀

CashQuiz est une plateforme web mobile-first permettant aux utilisateurs de l'Afrique de l'Ouest et de l'Afrique Centrale de gagner de l'argent en répondant à des quiz quotidiens de culture générale.

## Fonctionnalités :
- **20 quiz par jour** (250 FCFA par tâche validée, soit jusqu'à 5 000 FCFA / jour).
- **Couverture complète** : Tous les pays d'Afrique de l'Ouest et Centrale avec leurs indicatifs.
- **Paiement sécurisé** : Frais d'activation uniques (4 500 FCFA) et retraits via Mobile Money.
- **Panel Admin intégré** : Permet de suivre les inscriptions (heure, pays, numéro, email, nom) et de valider les comptes en un clic.
